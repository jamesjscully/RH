## F1 — THE NON-ADDITIVE DOOR (the only escape; the squeeze)

**Resolution.** The wall is proven (modulo W1) for ADDITIVE/localizing
invariants; the lone escape is a canonical-but-non-additive integer form. Since
non-additive = multiplicative, the door is a canonical MULTIPLICATIVE operation
— exactly the carrier wall's missing "multiplicativity as structure."

**Sharp open question — refined (doc 09).** The door is OCCUPIED but does not
escape: a canonical multiplicative structure at ∞ *exists* — the scaling flow
R₊^* / Deninger's Θ — but has **continuous spectrum**, so its self-intersection is
the transcendental −ζ′(0), not an integer. A finite place p has a *discrete*
Frobenius (lattice {q^{w/2}}); ∞ has a *continuous* flow. The real question is
now **Q: does a canonical DISCRETE (finite-q) Frobenius exist at ∞ — a
discretization of Θ?** YES ⇒ the missing object ⇒ RH; NO ⇒ the door shuts and the
theorem extends to the full canonical class.

**Status — SHUT for all known structures (doc 11).** The named mechanism:
**R₊^* has no canonical generator.** A discrete archimedean Frobenius = a
canonical generator of the value group = a canonical "q at ∞"; but R₊^* ≅ (R,+)
is connected with Aut acting transitively (no distinguished element), so the
choice is non-canonical — forbidden by S1. Every known canonical multiplicative
structure at ∞ is either *continuous* (the scaling flow R₊^*) or *trivial-finite*
(Z/2 conjugation; δ/Λ-rings have **no** ψ at ∞) — none a discrete q-Frobenius. So
the door shuts for the known canonical class, and continuous ⇒ transcendental
(Lindemann, F2). **The sole residual = an unknown exotic canonical "q at ∞" = the
F_1 problem itself** (the positive escape; the program can't adjudicate it from
inside).
**The squeeze — CORRECTED (doc 07).** doc 03 hoped "canonical ⟹ additive ⟹
door shuts." That implication is FALSE: canonical MULTIPLICATIVE structures (the
norm, the Frobenius, the δ-structure) are canonical yet non-additive. So the
squeeze does NOT close — it LOCATES the door precisely: the only escape is a
canonical *multiplicative* (norm/Frobenius/δ) integer structure at the
archimedean place. The door is open and is exactly the program's original target.
The deepest far-side question: does such an archimedean multiplicative structure
exist? (= F5's deficit closed.)

## F2 — THE TRANSCENDENTALITY BOUNDARY  [HARDENED to a theorem, doc 09]

**Resolution (Theorem-anchor, Lindemann).** Finite ⟹ the self-intersection is
−ζ′(0) = ½log2π = **½log2 + ½logπ**. The ½log2 part is finite-place type (in the
Q-span of {log p} — the prime 2, cf. CC's K=−2{2}); the **½logπ part is provably
NOT** in Q-span{log p} (else π=∏p^{c_p} would be algebraic, contra Lindemann). So
−ζ′(0) is **provably not finite-place type** — it cannot be a finite-Frobenius
lattice value. [Certified identity + sanity: `gf_archimedean_no_finite_q` exit 0;
transcendence: Lindemann.] The transcendental horn is now a theorem, not an
observation.

**Resolution (Reading, prior-arc named wall).** The wall = no truncation of the

Poisson. Map which (if any) supplies truncation past the FE.

## F4 — THE CLASS BOUNDARY  [RESOLVED, doc 07]

**Resolution.** C = integer-valued ADDITIVE/LOCALIZING invariants (Blumberg–
