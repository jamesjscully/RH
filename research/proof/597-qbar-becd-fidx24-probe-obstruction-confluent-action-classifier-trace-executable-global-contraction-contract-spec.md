# 597 - Qbar_BECD FIdx24 Probe Obstruction-Confluent Action Classifier Trace Executable Global Contraction Contract Spec

## Status

Construction-spec refinement anchor. Layer I only; this is not an RH result.

## Pinch

Doc 596 requires every obstruction class to force a bounded source-internal
action. That is still too weak if simultaneous actions do not commute or join:
the construction could hide an order choice in the way it handles several
localized obstructions.

Doc 597 requires action confluence. The finite action system must enumerate
all action critical pairs, join every pair inside the source-internal budget,
and produce a unique replayable action normal form. This makes bounded action
execution independent of obstruction order and prevents the action layer from
becoming a hidden branch selector.

1. The finite action system enumerates all action critical pairs.
2. Every critical pair joins to a unique source-internal normal form.

4. Repair, no-go, budget/context, sample, and trace actions cannot conflict
   or retune the action system.

## Fail-Closed Exclusions

Missing confluence certificates, class/action order dependence, action
conflicts, unresolved or incomplete critical pairs, failure of local/global
confluence, nonterminating joins, absent or nonunique normal forms,
nondeterministic or nonmonotone joins, external/oracle joins,
non-source-internal, proof-irrelevant, or nonextensional joins, branch
spawning, unbounded completion, repair/no-go/budget-context/sample conflicts,
trace-replay conflicts, retuned joins, new cells, context collapse,
declarations, finite samples, basis rows, and unbudgeted join systems are
diagnostics only.
