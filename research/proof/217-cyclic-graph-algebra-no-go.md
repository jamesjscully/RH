## 1. Purpose

Doc 216 says one cannot repair an off-circle graph by unitary projection
without changing the graph or importing a metric. The next natural repair is
more algebraic:

```text
Do not project F.
Use the cyclic graph algebra Z[F],
equip it with the involution F^dag = q F^{-1},
and read the trace/Rosati form on that algebra.
```

This is a real finite-field shadow. In genus one the Rosati trace Gram on
`span{1,F}` is

```text
[[2, a], [a, 2q]],
```

whose determinant is `4q-a^2`. Its positivity is the Hasse/Weil sign.

The issue is that this does not construct the square carrier. It is only the
`z`-component algebra after a graph has already been chosen. The finite-field
anchor in doc 211 requires correspondences represented as triples

```text
(d1, z, d2)
```

with intersection

```text
d1 e2 + d2 e1 - Tr(z w).
```

The cyclic algebra sees `z`; it does not determine the fiber degrees,
diagonal class, graph orientation, off-diagonal intersections, or the
carrier-native positivity theorem.

This document rejects only the shortcut:

```text
the cyclic graph algebra Z[F] with its trace/Rosati form constructs rep_NS
and therefore End(S^2/Z).
```

## 2. Lemma

```text
Lemma 217.1 (Z[F] is not the NS square).

Let F be a genus-one Frobenius-style graph with determinant q and trace a.
The cyclic algebra generated by F has a formal Rosati involution

    F^dag = q F^{-1}.

On the basis (1,F), the trace/Rosati Gram is

    [[2, a], [a, 2q]].

For the genuine finite-field block q=7, a=1, this Gram is positive. For the
off-circle integral q-similitude block q=2, a=3, the same algebra and
involution exist but the Gram is indefinite. Thus the cyclic trace form
detects the missing Weil sign; it does not construct it.

If one retunes the degree to the graph's own determinant, positivity can
hold relative to that self-degree. This is the doc-210 self-norm phenomenon,
not construction of the externally prescribed zeta base size.

Moreover Z[F] only records the End(H^1) component z. The NS square
correspondence needs the full triple (d1,z,d2). The same z=Id gives different
intersections for different choices of fiber degrees:

    Delta        = (1, Id, 1),
    fake_same_z  = (0, Id, 0).

Against Gamma_F=(q,F,1), these have different intersections. Therefore the
z-algebra does not determine the diagonal intersection data.

The same cyclic algebra, involution, and trace Gram are formable on arbitrary
control matrices without Euler product, Satake parameters, rep_NS, square
intersections, or carrier-native positivity.

Consequently cyclic graph algebra data constructs no rep_NS, NS triples,
diagonal, fiber degrees, off-diagonal intersections, positive Rosati,
DH/Epstein death, DD.4 weight>=1 datum, or End(S^2/Z).

Therefore Z[F] cannot itself be promoted to the square correspondence
carrier.
```

## 3. Proof

CGA1 records the genuine finite-field anchor. For `q=7`, `a=1`, the cyclic
algebra `span{1,F}` has Rosati relation residual zero and trace Gram

```text
[[2, 1], [1, 14]]
```

with determinant `27`, hence positive.

CGA2 records the off-circle integral graph from doc 215. For `q=2`, `a=3`,
the cyclic algebra and relation still exist, but the Gram is

```text
[[2, 3], [3, 4]]
```

with eigenvalues

```text
-0.162278, 6.162278.
```

Thus the cyclic trace form detects the positivity failure but does not repair
it.

CGA3 records the self-degree escape. For the graph with own determinant
`5`, the cyclic trace form is positive relative to `q=5`; relative to an
external prescribed `q=7`, the `q`-similitude defect is `2.828`. This is not
the zeta base-size construction.

CGA4 records the `rep_NS` failure. The true diagonal

```text
Delta = (1, Id, 1)
```

and the fake class

```text
(0, Id, 0)
```

have the same `z=Id` component. The cyclic algebra cannot distinguish them.
Their intersections with the same Frobenius graph differ:

```text
Delta . Gamma_F = 7,
fake . Gamma_F  = -1.
```

So the `z`-algebra is not the NS square.

CGA5 records control formability. The untyped control matrix
`[[1,1],[1,3]]` has a cyclic graph algebra, a determinant-`2` similitude
package, and a trace Gram, without Euler product, Satake parameters,
`rep_NS`, square intersections, or positive Rosati.

CGA6 records the construction failure: no `rep_NS`, NS triples, diagonal,
fiber degrees, off-diagonal intersections, positive Rosati, control death,
or DD.4 weight>=1 datum is constructed.
