# 613 - Qbar_BECD FIdx24 Residual Shared-Feature Quotient No-Go

## Status

No-go theorem with a named mechanism. Layer I only; this is not an RH result.

## Claim

The doc-612 residual 21 cases cannot be repaired by generating a quotient
relation from existing shared doc-610 source features.

The named mechanism is **shared-feature quotient collapse**.

## Setup

Doc 612 leaves 21 residual decisions without a reused class-pure containment
state. The next natural categorical repair is to quotient those residual events
by shared source features: connect two residual events when their doc-610
signatures share a primitive feature, then use connected components as
candidate residual class states.

The repair is tested under five feature profiles:

```text
all features
all features except boundary
all features except boundary and event kind
all features except boundary, event kind, and namespace
segmental features only
```

## Obstruction

The quotient never gives a total reused class-pure residual state system.

With all features, or with boundary removed, all 21 residual events lie in one
mixed component spanning all nine residual classes.

After removing boundary and event kind, the quotient has component sizes:

```text
18, 1, 1, 1
```

The 18-event component is still mixed and still spans all nine residual
classes; the other three components are singleton fragments.

After also removing namespace, or after keeping only segmental features, the
quotient has component sizes:

```text
12, 2, 1, 1, 1, 1, 1, 1, 1
```

The 12-event component is mixed across seven classes, the 2-event component is
also mixed, and seven components remain singleton.

## Consequence

Doc 613 does not rule out every possible categorical repair. It kills the
obvious repair generated by existing shared doc-610 source features. A real
repair of the residual 21 must add new source-native morphisms or quotient laws
not already present as shared doc-610 features, and it must do so without
exact-tail lookup, stem retuning, class collapse, or doc-602 anchor changes.
