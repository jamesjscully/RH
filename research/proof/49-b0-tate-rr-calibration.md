# 49 - B0 Tate-RR calibration

Status: construction branch, 2026-06-11. This is the smallest honest
calibration object from doc 46. It is not the missing carrier.

## 1. Purpose

Doc 46 says not to start by claiming the full liquid/index carrier.
Start with the first buildable subobject and ask what it proves and
what it cannot prove.

The object is:

```text
B0 = (L0, b0, R0/T0, tr0, comb_p, Count0).
```

Its job is to test whether the theorem-grade calibration shadow from
the Tate-curve / liquid-RR
shadow can touch the banked one-place prime comb without importing any
of the missing promotion data. If it fails, the construction branch
dies early. If it passes, it only authorizes the next build step.

## 2. Object

The components are deliberately minimal.

```text
L0
  The theorem-grade calibration shadow in the complex-shadow/liquid
  category for the
  Tate curve

      X_p = C^x / p^Z.

b0
  The q-expansion grading. It records the rank-one p^Z address and its
  log p spacing.

R0/T0
  The period/address datum only. The period lattice is generated by
  -log p and 2 pi. This is not yet an internal archimedean continuum
  unit on a full index form.

tr0
  The Serre/residue trace on the Tate-curve calibration object,
  normalized by res(dz/z) = 1.

comb_p
  The one-place Poisson comb carried by the p^Z grading.

Count0
  The elliptic RR count chi(L_d) = d for the positive-degree
  calibration line bundles, with chi(O) = 0.
```

No other fields are present. In particular B0 has no `U`, no `Fr`, no
`H_odd`, no index form `I`, no nonnegative cone value `N`, and no
comparison theorem `Compare`.

## 3. Witness

The executable witness is:

```text
python3 -m scripts.numerics.witness.prime_b0_tate_rr_calibration
```

It checks five gates.

```text
B0.1 RR count and Serre trace are p-independent.
  For p in 2,3,5,11 and degrees 0..8, chi(L_d)=d and tr0=res(dz/z)=1.
  The periods vary as (-log p, 2 pi), but Count0 and tr0 do not read
  those periods.

B0.2 The q-expansion address carries the p^Z comb.
  For Gaussian probes and p, p^2 controls, the witness verifies

      sum_n phihat(n log p)
        = (2 pi / log p) sum_k phi(2 pi k / log p)

  with worst relative discrepancy 3.92e-16.

B0.3 No promotion fields are present.
  The B0 field set is disjoint from U, Fr, H_odd, I, N, Compare.

B0.4 Epstein replacement kills the valuation/tower address.
  For Q=x^2+5y^2, the theta/count layer represents 1,4,6,9,36 while
  2 and 3 are absent. The represented-norm monoid has irreducibles
  4,6,9 but 36=4*9=6*6. Thus the count/Poisson shadow survives, while
  a free rank-one valuation or q-tower address is not formable.

B0.5 Calibration verdict.
  Route A produces a scale-free one-place null, not the missing carrier.
```

The run is deterministic and uses no zeta zeros, explicit-formula
signs, inserted continuum unit, odd-slot spectrum, Frobenius-index
form, or comparison theorem.

## 4. Interpretation

B0 passes as a calibration object. It shows that the program can place
the Tate/RR shadow against the p-comb address and reproduce the
expected one-place Poisson identity.

It also confirms the main warning from docs 45-46: the RR count and
Serre trace are scale-free. The only p-dependence in B0 is the address
spacing `log p` and its Poisson dual. That is address data, not yet an
index carrier.

The Epstein guard is the important honesty check. A theta/count layer
can still be formed for the Epstein represented-norm monoid, but the
valuation tower cannot. This is the right kind of failure: the shadow
survives, the carrier address does not.

## 5. Consequence

B0 authorizes exactly one conclusion:

```text
The one-place theorem-grade calibration shadow can touch the bank
and pass the first carrier guard, but it remains a scale-free null.
```

It does not satisfy doc 45 clauses A-E. In particular:

```text
A  It does not give a metric/liquid analytic-ring trace coupling on
   the full comb/continuum index form.
B  It does not build the Euler-product carrier, though the Epstein
   guard identifies the first required structural death point.
C  It has no derived unit.
D  It has no forced-nonnegative full-cone index/Gram value.
E  It has no odd slot and no independent second evaluation.
```

Therefore the next construction target is B1, not promotion of B0.
B1 must add the two-place or liquid/gaseous assembly where `log p`
remains visible before trace evaluation, where the Epstein replacement
is structurally unformable, and where LS3/LS4 can be tested against
the full doc-45 carrier clauses.
