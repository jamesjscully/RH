# 175 - PFV2 GPF residual monodromy passive extension-depth collapse

Status: bounded no-go from the PFV2-GPF-RMON-EXTDEPTH-SELECT target /
Q134.1 internal result, 2026-06-12. This is not a B1 construction, not
an external answer, and not a witness license. It kills only
extension-depth or structural filtration proposals where the filtration
is a passive functorial invariant of the complement rather than an
active residue generated by simultaneous p/q action.

## 1. Purpose

Doc 174 writes the extension-depth shot:

```text
PFV2-GPF-RMON-EXTDEPTH(p,q).
```

The first false positive after doc 174 is passive structurality:
`Fil_C^{edep}` may be genuinely structural and not scalar
bookkeeping, but still be functorially determined by the complement
alone. Such a filtration can evade doc 173 while remaining available
to broad local controls and invisible to the first-map residue.

## 2. Covered Class

Call a proposal `PFV2_GPF_EXTDEPTH_passive` if it satisfies all of:

```text
D175.1 extension-depth syntax
  The proposal names Ex_C^{p,q}, Fil_C^{edep}, rho_G^{edep}, and
  kappa_G^{edep} before an assembly functor.

D175.2 passive structural filtration
  Fil_C^{edep} is structural but functorially determined by
  C_{not p,q} alone, by a broad filtered local category, by a canonical
  slope/ramification/weight/depth filtration, or by an associated
  graded construction available before primitive PFV2 carrier checking.

D175.3 layerwise p/q action
  Act_p and Act_q preserve the filtration layerwise, or the induced
  commutator on gr(Fil_C^{edep}) is natural in the same broad category.

D175.4 inert first map
  Changing the p/q filtered action residue while holding the filtered
  complement object fixed does not change kappa_G^{edep} or its target.

D175.5 control formability
  Epstein/DH-style controls can instantiate the same filtered
  complement and induced graded action while retaining theta/count
  shadows.

D175.6 downstream shadow only
  M_C/F_C/Tr_L consumes only the filtered or graded shadow, not the
  primitive p/q commutator residue.
```

This class includes:

```text
canonical filtrations of C_{not p,q} functorial in broad local data;
slope/ramification/weight/depth filtrations not generated by p/q
  interaction;
associated-graded packages where p and q act layerwise;
extension-depth labels whose first maps see only the graded shadow;
filtered categories broad enough to admit Epstein/DH controls.
```

## 3. Lemma

### Lemma 175.1

`PFV2_GPF_EXTDEPTH_passive` does not satisfy PFV2-GPF-RMON-EXTDEPTH-SELECT.

Verdict:

```text
REJECT_EXTDEPTH_PASSIVE
  if Fil_C^{edep} is structural but passively functorial in the
  complement or a broad filtered local category.

REJECT_EXTDEPTH_LAYERWISE
  if the p/q action only preserves layers or induces a natural graded
  shadow rather than an active filtered residue.

REJECT_EXTDEPTH_INERT_MAP
  if kappa_G^{edep} is unchanged when the filtered commutator residue
  changes while the filtered complement shadow is fixed.

REJECT_CONTROL_FORMABLE
  if Epstein/DH controls can instantiate the same filtered shadow and
  graded action while retaining theta/count shadows.

HOLD_EXTDEPTH_ACTIVE
  if a later proposal supplies extension-depth layers created by the
  simultaneous p/q GPF action itself, with first-map dependence on the
  filtered residue.
```

### Proof

PFV2-GPF-RMON-EXTDEPTH-SELECT requires more than a structural
filtration. It requires the extension-depth filtration to be generated
by simultaneous p/q tower action inside the p,q+complement GPF source,
and it requires the resulting filtered action residue to be load-bearing
for the first map.

Under D175.1-D175.2, the proposal has extension-depth syntax but the
filtration is passive. It is determined by the complement or by a broad
filtered category before primitive PFV2 carrier checking. Therefore the
filtration is not the active residue of p/q interaction.

Under D175.3, the p and q actions do not create the layers. They merely
preserve them or act naturally on an associated graded. The commutator
seen downstream is then a shadow in the same broad category, not a
source-native obstruction unavailable to controls.

Under D175.4, first-map dependence fails. If varying the p/q filtered
action residue while fixing the filtered complement shadow leaves
`kappa_G^{edep}` unchanged, the first map consumes the passive
filtration rather than the primitive residue.

Under D175.5, control exclusion fails. A broad filtered category that
admits Epstein/DH controls while preserving theta/count shadows cannot
be the strict PFV2 carrier-selective source required by docs 64, 87,
97, 100, and 107.

Under D175.6, downstream dependence fails. If M_C/F_C/Tr_L sees only
the filtered or graded shadow, doc 111 rejects the route.

Therefore passive extension-depth filtrations do not satisfy
PFV2-GPF-RMON-EXTDEPTH-SELECT. QED.

## 4. What Passive Filtrations Still Supply

Allowed:

```text
normal forms for comparing later active p/q-generated filtrations;
calibration cases for structural-but-inert false positives;
external questions about which filtrations are merely functorial;
diagnostics for first-map and downstream dependence.
```

Not allowed:

```text
claiming PFV2-GPF-RMON-EXTDEPTH-SELECT;
claiming FIRST_MAP_PASS;
claiming control non-formability;
running an A2 witness;
promoting passive structurality to active p/q-generated residue;
updating doc 103 or doc 113 as passed.
```

## 5. Surviving Escape

The remaining PFV2 extension-depth route is:

```text
PFV2-GPF-RMON-EXTDEPTH-ACTIVE.
```

The target:

```text
There is a native extension structure Ex_C^{p,q} and filtration
Fil_C^{act} of C_{not p,q} whose layers are created by simultaneous p/q
tower action under GPF_{p,q} and Eff_{p,q}, not passively determined by
the complement or a broad filtered local category.

The p/q commutator changes the filtered residue rho_G^{act}; changing
rho_G^{act} while holding D, p,q marking, scalar PF, complement
bookkeeping, presentation data, and the passive filtered shadow fixed
changes kappa_G^{act} or its target; Epstein/DH controls cannot form
the same active residue; B0_p and B0_q embed conservatively; and
rho_G^{act} remains load-bearing in M_C/F_C/Tr_L.
```

This is narrower than PFV2-GPF-RMON-EXTDEPTH-SELECT because it removes
passive functorial structural filtrations.

## 6. Kill Conditions Licensed By This Shot

A future no-go is licensed only for a named active extension-depth
proposal:

```text
KILL-EXTDEPTH-ACTIVE.1 no active layer creation
  The proposed layers are not created by simultaneous p/q tower action.

KILL-EXTDEPTH-ACTIVE.2 passive shadow collapse
  The active residue is recovered from the filtered complement shadow,
  associated graded, broad filtered category, D, scalar PF, marking, or
  complement bookkeeping.

KILL-EXTDEPTH-ACTIVE.3 control formability
  Epstein/DH controls can instantiate the same active filtered residue
  and first map while retaining theta/count shadows.

KILL-EXTDEPTH-ACTIVE.4 inherited first map
  kappa_G^{act} is unchanged when the active filtered residue changes
  while D, marking, scalar PF, complement bookkeeping, presentation
  data, and passive filtered shadow are fixed.

KILL-EXTDEPTH-ACTIVE.5 bank replacement
  the active extension-depth source requires replacing B0_p/B0_q by a
  full global source.

KILL-EXTDEPTH-ACTIVE.6 downstream erasure
  every legal M_C/F_C/Tr_L forgets rho_G^{act}.
```

Do not apply these beyond the named active extension-depth proposal.
