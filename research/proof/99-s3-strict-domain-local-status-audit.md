## 3. Remaining Positive Target

The only S3 route still open in the local record is the doc-113 matrix:
a doc-103 strict first-map record that survives docs 109, 111, and 112,
followed by the doc-98 `ECar_L1` target:

```text
ECar_L1
  A strict Euler-carrier trace domain whose objects require primitive
  carrier fields before trace evaluation.

trace theorem
  A named trace/properness/duality/nuclearity theorem applying to
  ECar_L1 objects and to the needed kernels/correspondences.

bank embedding
  A conservative b1(comb_C) preserving B0 p^Z comb, q/log p address,
  Count0/RR layer, graph-depth data if claimed, and Epstein guard.

same-form coupling
  One mixed M_C receiving b1(comb_C) and R_L/T_C before trace, with
  the trace deriving the same-form codomain F_C.

control exclusion
  Epstein and DH may retain theta/count or measure shadows, but they
  must fail to be ECar_L1 objects or fail at the first carrier-consuming
  map.

downstream dependence
  The primitive field consumed first must remain load-bearing in M_C,
  F_C, or Tr_L. It cannot be forgotten and reintroduced later.

freeze
  ECar_L1, b1, M_C, F_C, control exclusions, and first zero contact are
  frozen before zero-side comparison.
```

A proposal that supplies only some of these fields remains
`HOLD_STRICT_EULER`. A later positivity, count, or diagnostic pass
cannot compensate for any missing field above.

```text
  Doc 98 names this as NSE98.1, but the program has not proved it.

no conservative bank embedding
  Doc 89 supplies the ledger; it does not prove B0 cannot embed into
  every strict Euler trace domain.

no same-form mixed object
  Docs 79 and 86 reject side-blocks, not every possible mixed object.

forced shadow enlargement
  Doc 97 kills overbroad naturality domains, but does not prove every
  trace domain rich enough for M_C must become overbroad.
```

Thus the honest local verdict is not `REJECT_S3`. It is
`HOLD_STRICT_EULER` until an external theorem, a local no-go, or a
candidate fills doc 98.

Classify any future S3 proposal by the earliest broken gate:

```text

  before bank, coupling, carrier, positivity, or witness claims.

REJECT_BANK
  before same-form or carrier claims if the B0 comb/address/count/guard
  data are not embedded conservatively.

REJECT_SIDE_BLOCK
  before carrier claims if bank and continuum are evaluated separately.

REJECT_CARRIER_OVERREACH
  before positivity or Count/Compare claims if Epstein/DH still enter
  the same trace domain.

  before witness talk if the carrier-reading form/codomain is supplied
  externally.

  whenever any domain, form, map, constant, exclusion, or first zero
  contact is selected after zero-side comparison.
```

No later pass promotes an earlier failure.
