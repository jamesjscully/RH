# 60 - Gate stack and B1 escape profile

Status: synthesis/gating document, 2026-06-11. This consolidates docs
49-128 into one operational admission test for future construction
work. It is not a new theorem and not a construction.

## 1. Purpose

Doc 45 gives the target package:

```text
M = (L, b, R/T, U, Fr, H_odd, I, N, Count, Compare).
```

Docs 51-59 give the broad no-go gates that prevent old shadows from
being re-promoted, and docs 62-128 harden those gates into operational
lemmas, ledgers, routers, audits, packets, and meta-lemmas. Doc 83
controls LT76 answer propagation. The
next useful construction must not merely avoid one failure mode. It
must escape the whole stack at once.

This document states the minimal pre-witness rule:

```text
Do not build another numerical witness for a candidate until it has
answered G60.1-G60.10 below.
```

B0 is exempt because it was explicitly a calibration object. B1 is not.

## 4. B1 Admission

B1 is the first post-B0 construction target. Its admissible minimum is
smaller than the full doc-45 package but larger than B0.

To be admitted as B1, a proposal must pass:

```text
required for B1:
  G60.1 carrier selectivity;
  G60.2 scale retention;
  G60.3 internal R/T or a stated partial replacement;
  G60.4 LS3 status, at least honestly open;
  G60.5 same-form LS4 coupling;
  G60.10 zero-free freeze.

allowed to remain open at B1:
  G60.6 full class family;
  G60.7 forced nonnegativity;
  G60.8 odd-slot supplier;
  G60.9 independent Count and Compare.
```

If G60.6-G60.9 are present in a B1 proposal, they must satisfy their
gates. But B1 may be only an A/B/C-front construction if it honestly
labels D/E as open.

The core B1 verdicts are:

```text
REJECT
  Any required B1 gate fails.

HOLD
  Scale or carrier structure is plausible, but the LS4 coupling or
  Epstein death map is not written.

ADMIT
  The proposal names retained log p, a conservative bank embedding,
  same-form LS4 coupling, and carrier/effectivity death for Epstein.
```
