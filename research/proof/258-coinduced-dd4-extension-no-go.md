## 1. Purpose

Coinduction is the obvious cohomological way to remove the obstruction.
For the order-two group generated by the Weyl shear, a coinduced module is
acyclic for `H^1`. Thus it is important to test it directly rather than
leave it as an attractive but unexamined escape.

This document rejects only the shortcut:

```text
H^1(Coind(U_1)) = 0, therefore DD.4/SCC is constructed.
```

The equality is true. The conclusion is false. Coinduction kills the class
by changing the coefficient system to a two-copy formal module. It does not
construct the square carrier, `rep_NS`, degree maps, boundary/properness,
projection formula, Rosati pairing, or control death.

## 2. Lemma

```text
Lemma 258.1 (coinduced DD.4 extension is not a carrier construction).

Let

    U_1 = 1 + z F_2[[z]]

with Artin-Schreier shear

    phi(z) = z/(1+z),

and let

    c = (1+z)^-1.

In the base coefficient system, for truncations L=6,8,10,12:

    H^1(<phi>; U_1) = Z/2,
    [c] != 0,
    res_1(c)=1.

Now form the coinduced two-copy coefficient system

    Coind(U_1) = U_1 x U_1,
    sigma(a,b) = (phi(b), phi(a)).

Then in the same truncations:

    H^1(<sigma>; Coind(U_1)) = 0.

The diagonal image of the obstruction is a coboundary:

    diag(c) = (c,c) = (c,1) / sigma(c,1).

Therefore coinduction really does kill the DD.4 class.

However, this operation doubles coefficient support:

    L=6:  6 -> 12,
    L=8:  8 -> 16,
    L=10: 10 -> 20,
    L=12: 12 -> 24.

It is functorially formable for any C_2-module and hence for arbitrary
controls. It constructs no actual square, integral rep_NS, two degree maps,
indecomposable diagonal, Frobenius graph, proper correspondence category,
fiber-product composition, projection formula, canonical Rosati, positive
primitive sign, carrier boundary, or control death.

Consequently coinduced DD.4 extension is not construction-grade
End(S^2/Z). A surviving route must make the obstruction die through a
carrier-native boundary/properness/self-duality map, not through acyclic
replacement of the coefficient module.
```
