## 1. Purpose

After doc 341, the cheap repair is:

```text
declare a source-typed functor/fibration of admissible strict-square points,
then use Yoneda or a formal universal property to call it represented.
```

That is still not a carrier. A functor of points is useful after a
representing object exists. It is not the representing object. Likewise, a
predicate subfibration still classifies already-formed graph objects, and a
local source table chooses lifts row by row rather than producing cartesian
transport.

The live branch therefore narrows from "source-typed formation fiber" to:

```text
construct an actual represented source fiber

    Rep_Qbar_BECD_source_fiber --eta_Qbar_BECD_source-->
    SRC_Qbar_BECD_strict_square -> Fib_Qbar_BECD_graph_formation

with cartesian lifts for C3, C9, F22, and C3F22, so that
C3 composed with C3 gives the C9 lift and C3/F22 transports commute through
the same representer.
```

Controls, DH, and Epstein must fail by not being points of this representing
object, not by failing a specification predicate.
