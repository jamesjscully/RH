## 1. Purpose

Doc 206 rejects one operator abstraction. The immediate repair is
categorical:

```text
Do not ask one operator to supply the radius directly.
Instead, put F into the rigid Tannakian category it generates.
Then compactness/polarizability of the reconstructed group should force the
radius.
```

The finite-field analogy is real. For pure Frobenius, after normalization
by `sqrt(q)`, the Sato-Tate closure is compact and one has a positive
fiber functor / polarization. The issue is whether this compactness is
forced by rigid Tannakian consistency, or whether it is exactly the missing
positive Rosati input in categorical language.

The tested shortcut is:

```text
Rep(<F>_Zar) as a rigid Tannakian category itself supplies compactness,
polarizability, and therefore End(S^2/Z).
```

## 2. Lemma

```text
Lemma 207.1 (Rigid Tannakian reconstruction does not force compactness).

Let F be an invertible semisimple Frobenius-style operator. The rigid
Tannakian category generated by F, `Rep(<F>_Zar)`, has duals, finite tensor
spectra, and well-defined traces for pure and off-purity F alike. This is
Step A: rigidity/duality/functional-equation shape.

There are off-purity configurations preserving the count scale
`|det F|=q^g` while breaking radius. For such F, `Rep(<F>_Zar)` is still a
consistent rigid tensor category. Thus rigid Tannakian reconstruction does
not reject off-purity data.

The normalized Sato-Tate closure is compact, and a positive/unitary fiber
functor exists, exactly when the normalized eigenvalues lie on the unit
circle. Off-purity examples have a noncompact scaling direction and are
non-polarizable, while remaining rigid and tensor-consistent.

Consequently compactness/polarizability is not created by Tannakian
coherence. It is an extra positive structure equivalent to the radius
condition. Imposing it is importing the missing polarization/Rosati datum.

Moreover the construction consumes only an invertible spectral operator. It
does not use an Euler product, effectivity, multiplicativity, or a
compactified square correspondence, and therefore is not a DH/Epstein
carrier guard.

Therefore Frobenius-first Tannakian compactness does not construct a
carrier-native q-power map, compact Sato-Tate group, positive fiber functor,
polarization relation, uniform modulus bound, DH-killing carrier, finite
constant field, square-side iota/properness theorem, square H2,
intersection form, correspondence algebra, Frobenius graph, Laurent
boundary data, torsor splitter, DD.4 weight>=1 datum, or positive Rosati.

So the Frobenius-first Tannakian compactness package cannot itself be
promoted to End(S^2/Z).
```

Verdict label:

