## 1. Purpose

After doc 329, the cheap repair is:

```text
construct a boundary image for z = 2[1] - [2],
then separately use character convolution downstream.
```

That still does not construct the square. Boundary formation must be stable
under the same character convolution that supplies the strict-square source.
If the cancellation generator is multiplied by another character, the
resulting cancellation must map through the same boundary module functor and
then to the same DD.4 localization/stratum product.

The live branch therefore narrows from "boundary cancellation exists" to:

```text
construct a represented boundary-convolution module functor from the
cancellation module generated by z=2[1]-[2] under strict-square character
convolution to DD.4 boundary localization and Qbar_BECD stratum product.
```

## 2. Lemma

```text
Lemma 330.1 (one-off cancellation is not a boundary-convolution module).

Let z = 2[1] - [2]. The strict-square character action gives distinct
balanced translates:

    z*1    = 2[1] - [2],
    z*L    = 2[1] + [2] - [4],
    z*C3   = 2[3] - [6],
    z*F22  = 4[2] - 2[4],
    z*F41  = 2[4] - [8].

Each has weighted mass zero, but they are not the same boundary datum. A
weighted-zero subspace also accepts non-square profiles such as

    4[1] - [4],

which is balanced but is not one of these strict-square convolution
translates. Positive/negative split pairs record, for example,

    z*F22 = (4[2], 2[4]),
    z*F41 = (2[4], [8]),

but they do not supply functoriality. Support-only modules identify
coefficient/sign-distinct elements. Post-convolution quotients and absorbing
boundary ideals kill the multiplier data before it can feed the stratum
product. Finite multiplier samples do not prove totality on the character
subalgebra. Endpoint/control/DH/Epstein filters can mimic balanced
translates.

Thus the accepted datum is exactly:

    carrier-native,
    actual signed character algebra,
    actual signed zero generator,
    actual character convolution action,
    actual cancellation module,
    actual boundary-convolution module functor,
    actual DD.4 boundary localization,
    multiplier data preserved,
    coefficients preserved,
    signed support preserved,
    module action total on the character subalgebra,
    zero generator mapped to boundary,
    all convolution translates mapped to boundary,
    module action mapped to stratum product,
    endpoint integrality generated,
    pushforward compatibility generated,
    graph/Rosati/count data generated,
    control death generated,
    controls undefined at the module,
    DH undefined at the module,
    Epstein undefined at the module,
    no zero-fiber-only boundary,
    no weighted-zero subspace,
    no positive/negative split only,
    no group-completion only,
    no post-convolution quotient,
    no absorbing boundary ideal,
    no support-only module,
    no finite multiplier sample,
    no external module presentation,
    no endpoint-kernel filter,
    no declared module functor,
    not formable on controls, DH, or Epstein.
```

Verdict label:

