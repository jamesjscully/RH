## 7. Program Consequence

The first concrete B1 work should target S3, not because S3 is
admitted, but because it has the smallest missing object:

```text
write a zero-free explicit kernel K_p pairing the banked p^Z comb with
R on one same-form object, then prove before computation whether K_p
is undefined for the Epstein represented-norm monoid.
```

If that cannot be written, the next best work is not a witness. It is
an external theorem question for S1/S2:

```text
Does any liquid/gaseous or metric-equivariant trace retain the length
log p through trace evaluation strongly enough to define a same-form
comb-continuum coupling?
```

The S5 route supplies the sharper version of that external theorem
question: use doc 77, score by doc 83, land in doc 61, and route
through doc 92 before changing this ledger.

Until one of these entries changes from `HOLD` to `ADVANCE`, B1
remains a ledger, not a construction.

The first upgrade required for every slot is a doc-69 freeze record.
Absence of zero input is not enough; the load-bearing choices must be
fixed before any zero comparison can be permitted.

Doc 73 gives the S3 preregistration. It still leaves `K_B1` blank; a
new witness is licensed only after that same-form coupling is written
or S3 is rejected as carrier-blind, free-weight calibration, or
doc-94 trace-derived-form failure.
