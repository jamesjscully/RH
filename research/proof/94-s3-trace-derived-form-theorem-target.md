# 94 - S3 trace-derived form and codomain theorem target

Status: theorem target / S3 escape boundary, 2026-06-11. This states
the exact positive theorem needed for an S3 kernel to escape doc 93.
It is not a construction and does not authorize a witness.

## 1. Purpose

Docs 74 and 93 remove the two cheap S3 false positives:

```text
doc 74
  generic theta/count/Poisson or discrete-measure kernels;

doc 93
  valuation/depth-decorated kernels whose weights, windows, bilinear
  forms, stress parameters, determinant wrappers, or codomains are
  externally supplied.
```

The only remaining S3 escape is a theorem saying the form that reads
the carrier is produced by the candidate trace itself.

## 2. Positive Theorem Target

A positive S3 answer must provide:

```text
TD94.1 category and trace
  A category L1 and trace theorem strong enough to define the proposed
  comb-continuum trace before evaluation.

TD94.2 conservative bank input
  A map b1(comb_C) preserving the B0 p^Z comb, q/log p address,
  Count0/RR layer, graph-depth data if claimed, and Epstein guard.

TD94.3 mixed object
  One mixed object M_C receiving both b1(comb_C) and the continuum
  R_L/T_C before trace evaluation.

TD94.4 trace-derived form
  The weight, window, bilinear form, stress response, determinant
  presentation, regularization rule, or codomain is forced by the L1
  trace theorem or by one named same-form index/Gram/count object F_C.
  It is not chosen externally.

TD94.5 carrier selectivity
  The same theorem requires carrier fields (A, alpha, v, depth, ell,
  mu_C) and has a named carrier/effectivity failure point for
  Epstein/DH while theta/count shadows may remain meaningful.

TD94.6 zero-free freeze
  All formulas, constants, loci, class choices, units, forms, and
  first zero contact are recorded before zero-side comparison.
```

Passing TD94 advances only the S3/B1 construction ledger fields it
actually fills. It does not prove LS3, P3, Count/Compare, BC13,
positivity, RH, or full B1 admission.

## 3. Negative Theorem Target

A negative S3 answer is equally useful if it proves one of:

```text
NT94.1 trace-derived form impossibility
  In the named L1 or trace formalism, every carrier-depth form must be
  externally supplied rather than trace-derived.

NT94.2 side-block collapse
  Every available trace separates into bank-only and archimedean-only
  pieces before evaluation.

NT94.3 shadow collapse
  Every trace-derived form factors through theta/count/Poisson,
  discrete-measure, determinant-shadow, or represented-norm data and
  is rejected by doc 74.

NT94.4 free-weight collapse
  Every valuation/depth-sensitive trace in the class depends on a
  freely chosen weight, window, bilinear form, deformation, stress
  rule, regularization, or codomain and is rejected by doc 93.

NT94.5 carrier overreach
  Any trace broad enough to define the proposed S3 form also computes
  for Epstein/DH controls, so carrier/effectivity death fails.
```

The no-go must state its hypotheses. If it covers only a narrow
subclass, record `SHARPEN` rather than killing S3.

## 5. Decision Rule

```text
PASS_TRACE_DERIVED
  All TD94 fields are supplied. Route the result to docs 71, 72, 75,
  86, 87, 89, and 91 before any witness.

HOLD_TRACE_DERIVED
  A plausible trace-derived form is named, but the mixed object,
  carrier death, bank preservation, or freeze record is incomplete.

REJECT_SHADOW
  The trace-derived object factors through a doc-74 shadow.

REJECT_FREE_WEIGHT
  The carrier-sensitive form is externally supplied and doc 93 applies.

REJECT_SIDE_BLOCK
  The archimedean contribution separates before evaluation and doc 79
  applies.

REJECT_CARRIER_OVERREACH
  The same trace/form computes for Epstein/DH controls.

OUT_OF_SCOPE
  The answer concerns a trace, kernel, determinant, or comparison but
  does not decide whether the S3 form is trace-derived.
```

## 6. Collapse Router

```text
NO94.1 Free-form collapse
  If the codomain, form, weight, window, deformation, or bilinear
  pairing is externally supplied, fitted, chosen for convenience, or
  chosen after comparison, route to doc 93.

NO94.2 Side-block collapse
  If bank and continuum are evaluated separately and combined later,
  route to docs 79 and 86.

NO94.3 Generic-shadow collapse
  If K_B1 factors through theta/count/Poisson/discrete-measure data
  only, route to docs 74 and 87.

NO94.4 Bare-scale collapse
  If log alpha survives only as R/(log alpha)Z homotopy or bare-circle
  data, route to docs 81, 82, and 85.

NO94.5 Trace illegality
  If T_C -> pt or M_C is not trace-class/proper/nuclear/dualizable in
  the claimed category, route to doc 88.

NO94.6 Internal-R failure
  If R_L/T_C is external notation rather than internal structure,
  route to doc 90.

NO94.7 Freeze failure
  If any load-bearing form, domain, constant, or codomain is chosen
  after zero-side contact, route to doc 91.
```
