## 3. Missing Theorem

The S2 route is concentrated in:

```text
METEQ-A1.
There exists a category L1^meteq, an enriched circle T_p^met, and a
trace/proper-pushforward theorem Tr_met such that:

1. log p is retained as object/domain data before trace evaluation;
2. replacing log p by arbitrary l > 0 changes the trace domain or
   trace value by theorem, not by post-trace normalization;
3. the theorem does not factor through bare Shv(S^1), bare
   localizing invariants, or the scale-blind B_l diagram;
4. the same enriched datum can enter a same-form LS4 object receiving
   both b1(p^Z) comb data and the continuum before evaluation;
5. all data are zero-free.
```

METEQ-A1 would pass only A1/G60.2/LT76.1. It would not by itself prove
carrier selectivity, LS4, trace legality for B1, internal R/T, Count,
Compare, positivity, or RH.

## 7. What Would Kill S2

S2 should be rejected for a named class if one proves:

```text
KILL-S2.1 factor-through
  Every metric/equivariant enriched trace in the class factors through
  the bare scale-blind diagram before evaluation.

KILL-S2.2 late normalization
  Every log p dependence in the class enters only through Haar
  density, Poisson normalization, determinant normalization, or
  post-trace scale insertion.

KILL-S2.3 no trace theorem
  Enriched metric/equivariant circles strong enough to retain log p
  lack the needed traceability/proper-pushforward theorem.

KILL-S2.4 side-block
  The enriched circle trace cannot enter the same mixed object as the
  banked comb; it remains an archimedean side block.

KILL-S2.5 carrier overreach
  Any enriched trace package broad enough for LS4 also accepts
  Epstein/DH controls at the same typed domain.
```

KILL-S2.1 and KILL-S2.2 are the priority no-go targets. KILL-S2.5
belongs to the later carrier-selectivity board if A1 ever passes.
