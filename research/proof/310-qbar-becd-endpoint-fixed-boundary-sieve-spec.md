## 2. Lemma

```text
Lemma 310.1 (endpoint-fixed boundary sieve).

On the current Connes-Consani/CxC product line, grant:

    O = actual Qbar/Q/dQ,
    E = product p1,p2 and proper pushforward.

The represented Phase-A slots are then:

    carrier_object, endpoint_maps.

Adding product boundary shape and normal-crossing boundary directions does
not add:

    DD.4_boundary_killing.

In the tested `[-2,2]^2` normal-crossing window there are 16 primitive
directions, so product boundary shape exposes a family rather than selecting
the DD.4 primitive direction.

The endpoint-fixed boundary problem is the 16-branch atom sieve generated by:

    M = actual boundary map,
    L = exact localization,
    Z = DD.4 class mapped to zero,
    S = self-dual boundary/properness data.

Only M+L+Z+S represents DD.4 boundary killing. Deleting any one atom removes
the represented `DD.4_boundary_killing` slot.

The base DD.4 obstruction remains nonzero. In truncations L=6,8,10,12:

    H^1(<phi>; 1+z F_2[[z]]) = Z/2,
    [(1+z)^-1] != 0,
    res_1((1+z)^-1)=1.

Thus M+L+S without Z is not enough. Also M+L+Z without S is not enough:
self-dual boundary/properness is part of Phase A, not downstream decoration.

Declared boundary localization, declared exactness, declared DD.4 zero, and
declared self-duality do not count as represented B.

If actual B is constructed on the O+E line, the represented Phase-A slots are:

    carrier_object, endpoint_maps, DD.4_boundary_killing.

The only Phase-A slot left is then:

    control_death.
```

Verdict label:

```text
N1B_QBAR_BECD_ENDPOINT_FIXED_BOUNDARY_SIEVE__ACTUAL_B_THEN_CONTROL_DEATH__SPEC.
```

## 3. Proof

`prime_int_n1b_qbar_becd_endpoint_fixed_boundary_sieve` verifies eight gates.

BDS1 imports the doc-289 product probe into the doc-309 Phase-A sieve:
product endpoints give `carrier_object, endpoint_maps`, while product
boundary shape still gives only those two slots.

BDS2 checks that product normal crossings expose 16 primitive directions in
the tested `[-2,2]^2` window but do not select the DD.4 map.

BDS3 enumerates the 16 atom branches of the endpoint-fixed boundary problem.
Only `map+exact+zero+selfdual` completes B.

BDS4 deletes each atom from full B and checks that `DD.4_boundary_killing`
disappears every time.

BDS5 recomputes DD.4:

```text
L6:  |B|=2^3, |Z1|=2^4, |H1|=2
L8:  |B|=2^4, |Z1|=2^5, |H1|=2
L10: |B|=2^5, |Z1|=2^6, |H1|=2
L12: |B|=2^6, |Z1|=2^7, |H1|=2
```

and verifies that no branch missing the actual zero map kills the class.

BDS6 checks that `map+exact+zero` without self-dual boundary/properness is
still not represented Phase-A boundary.

BDS7 rejects declared boundary localization and declared DD.4 zero.

BDS8 records the next branch: if actual B is built on O+E, the only remaining
Phase-A slot is formation-level control death.
