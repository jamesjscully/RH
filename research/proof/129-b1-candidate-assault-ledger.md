## 1. Purpose

Docs 49-128 prevented false promotion of calibrated shadows. They also
created a risk: the program can keep adding perimeter no-goes without
forcing the remaining routes to produce objects.

The correction is not to abandon no-goes or witnesses. They are the
reason the target has stayed honest. The correction is:

```text
No-goes and witnesses should be driven by candidate shots.
```

Every new restriction should be paid for by one of:

```text
1. a concrete candidate attempt;
2. a returned external answer;
3. a theorem-polish step for a gate already used by a candidate;
4. a witness that measures a boundary exposed by a failed candidate.
```

Do not add a new gate just because it is expressible. Add it only when
it changes a live candidate row, a doc-116 HOLD row, or a sendable
external decision.

## 2. Candidate-Driven Loop

The current operating loop is:

```text
candidate shot
  -> name the first object/map/trace package concretely
  -> run the relevant existing gate matrix
  -> classify the earliest failure or local pass
  -> if failure is structural, generalize only to the class it covers
  -> if failure is boundary/numerical, build a fail-closed witness
  -> update doc 71/doc 116/doc 129 and any directly affected gate
  -> return to the candidate board
```

This loop keeps the existing discipline:

```text
pre-register before computation;
fail closed;
record negatives as full-value;
keep zero-free freeze;
do not promote analogy;
make Epstein/DH die at carrier/effectivity, not at signs.
```

It also adds a convergence rule:

```text
No candidate-free gate expansion.
```

## 7. Criteria For New Witnesses

A new witness is licensed only after a row names a concrete object or
boundary phenomenon.

Allowed witness roles:

```text
calibration:
  Measure the exact boundary where a candidate stops before promotion.

deletion test:
  Verify that a frozen enriched trace/domain changes under
  log p -> l, without zero-side input.

control test:
  Check formability or non-formability for Epstein/DH at the candidate
  map level, not sign or fit.

regression:
  Preserve a banked boundary after a theorem target is sharpened.
```

Disallowed witness roles:

```text
free kernel search;
zero-side fit;
post-trace log p repair;
positivity scan before B1 admission;
another B0-style calibration promoted as carrier evidence.
```
