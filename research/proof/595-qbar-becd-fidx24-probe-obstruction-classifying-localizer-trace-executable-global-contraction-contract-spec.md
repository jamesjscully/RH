## Status

## Pinch

Doc 594 requires every verifier rejection to produce a canonical localized
obstruction. That is still too weak if each localized obstruction opens a new
bespoke branch. Localization tells us where failure lives, but not whether the
failure is fatal, repairable within an existing requirement, a dependency gap,
a budget/context failure, or an illicit external/sample presentation move.

Doc 595 requires obstruction classification. The obstruction-localizing
verifier trace executable global contraction must classify every localized
obstruction by a finite source-internal taxonomy. Each class must carry a
proof-relevant link to existing repair/no-go evidence, a named kill-frontier
target, and the budget/context class when applicable. This keeps the negative
thread alive without letting the search fragment into untracked obstruction
families.
