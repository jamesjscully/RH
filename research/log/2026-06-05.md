## Findings that change the docs

1. **Kernel-norm constant corrected.** With <f,g> = (1/2pi) int f(tau+it) conj g dt,
   the reproducing kernel of H^2(Omega_tau) has **||k_rho||^2 = 1/(2(beta-tau))**
   (verified analytically + numerically), NOT 1/(4pi(beta-tau)) as first written. It is
   **T-independent** (translation invariance), so the barrier bound's height decay comes
   solely from |u(rho)| ~ 1/T:
       dist(u, V_N(tau)) >= |u(rho)| * sqrt(2(beta-tau)),  all N.
2. **Conditioning is N-driven, not tau-driven.** kappa(G_{N,tau}) scan (zeta): as
   tau -> 1/2 (0.90 -> 0.52) kappa is flat or slightly DECREASES; it grows with N
   (~ N^2-ish: N=3,5,7,9 -> ~22,70,160,310 at tau=0.7). So failure-mode 13.3
   ("conditioning blow-up as tau -> 1/2") is, empirically, mis-stated: the real
   conditioning cost is the N -> infinity limit (classical near-dependence of n^{-s}),
   not the deformation. Certified kappa(G_4,0.7) = 43.67 via `acb_mat.eig`.

## Follow-ups done same day: F4 + L3

**F4 (forward bound).** `scripts/numerics/witness/forward_bound.py` charts the central
quantity `||phi_tau M_N||^2 = mu^T G mu`. **Proved unconditionally for tau>1:**
`||phi_tau M_N||^2 <= zeta(tau)^2 ||phi_tau||^2` uniformly in N (triangle ineq on
|M_N| <= zeta(tau)), hence bounded -> (Wei-Wu) reproves zeta zero-free in Re s>1 in
bounded-norm form. Fails for DH (no mu). Numerically: bounded/convergent for tau>1;
oscillates with growing amplitude as tau->1/2 for tau<1; crude bound diverges at
tau->1. The real crux (open) is bounding the off-diagonal Mertens sum for a fixed
tau_0<1 via mu-cancellation. See `forward-theorem.md` Section F4.
