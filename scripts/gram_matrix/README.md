# Gram Matrix Scripts

This directory will contain scripts for deriving and experimenting with finite Gram matrices for the half-plane module witness spaces:

\[
V_N(\tau)=\{\phi_\tau(s)D_N(s): D_N(s)=\sum_{n\le N}a_n n^{-s}\}.
\]

Initial tasks:

- compute candidate matrix entries,
- compare symbolic and numerical formulas,
- measure condition numbers,
- export data for research logs.
